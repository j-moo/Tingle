# Tingle 포팅 매뉴얼 4 — 시연 시나리오

**Tingle**은 키링을 달고 다니다가 오프라인에서 스쳐 간 사람 중 조건이 맞는 상대를 찾아 주는 소개팅 서비스다.
시연은 두 사람(A, B)이 각자 폰과 키링을 들고 진행한다.

## 준비물

| 항목 | 내용 |
|---|---|
| 폰 2대 | Android, Tingle 앱 설치 (`https://k15e106.p.ssafy.io/app/latest.apk`) |
| 키링 2개 | 펌웨어가 들어 있고 서버에 정품 인증된 보드, 충전된 상태 |
| 계정 2개 | 성별이 서로 다른 소셜 계정 (A: 남성, B: 여성) |
| 사전 확인 | 폰의 블루투스·위치 켜기, 두 계정이 서로 차단·기존 매칭 관계가 없을 것 |

> 시간을 줄이려면 1~6단계(가입)는 한 사람만 직접 보여 주고, 다른 사람은 미리 가입해 둔다.

## 시연 순서

### 1. 로그인

| 화면 | 동작 | 결과 |
|---|---|---|
| 로그인 ("반갑습니다 / 로그인해 주세요") | **카카오 로그인** 버튼을 누른다 (Google·네이버도 가능) | 카카오 인증 후 "로그인했어요 · 다음은 서비스 이용 동의예요." |

### 2. 약관 동의

| 화면 | 동작 | 결과 |
|---|---|---|
| 약관 및 동의 | **전체 동의 (선택 항목 포함)** 을 체크하고 아래 **다음** 을 누른다. 각 항목의 **내용 보기** 로 전문을 볼 수 있다 | "동의를 저장했어요" → 키링 등록 화면 |

### 3. 키링 등록

| 화면 | 동작 | 결과 |
|---|---|---|
| 접근 권한 안내 | **확인** 을 누르고 블루투스·위치 권한을 허용한다 | 키링 등록 화면 |
| "키링을 등록해 주세요" | **키링 찾기** 를 누른다. 키링을 폰 가까이 둔다 | 주변 키링이 목록에 뜬다 |
| 키링 선택 | 내 키링을 누르고 **이 키링 등록하기** → 확인 창에서 **등록하기** | "키링을 등록했어요." → **다음** |

설명 포인트: 키링이 가진 고유 키로 서버가 정품인지 확인한다. 남의 키링이나 복제품은 등록되지 않는다.

### 4. 프로필 작성

| 화면 | 동작 | 결과 |
|---|---|---|
| 내 프로필 | 닉네임(2~20자), 생년월일 8자리, 성별, 흡연·음주 등 항목과 자기소개를 입력하고 **다음** | 성향테스트로 이동 |

설명 포인트: 만 19세 미만은 가입할 수 없다("서비스 이용 연령 안내").

### 5. 성향테스트

| 화면 | 동작 | 결과 |
|---|---|---|
| 성향테스트 ("n / 100 문항") | 문항마다 답을 하나 고르고 **다음**. 답할 때마다 자동 저장된다 | 마지막에 "모든 문항에 답했어요" |
| 제출 | **답변 제출하기** 를 누른다 | 분석 결과가 준비되고 매칭 조건 설정으로 이동 |

> 시연에서는 미리 답을 채워 둔 계정으로 **이어서 하기 → 답변 제출하기** 만 보여 준다.

### 6. 희망 조건과 첫 동기화

| 화면 | 동작 | 결과 |
|---|---|---|
| 희망 나이 ("어떤 나이의 상대를 만나고 싶나요?") | **범위 정하기** 로 최소·최대 나이를 넣거나 **나이는 상관없어요** 를 고르고 **저장하고 계속하기** | 키링 동기화 단계 |
| 키링 설정 동기화 | **최신 설정 보내기** 를 누른다. 키링을 폰 가까이 둔다 | "키링에 설정을 보냈어요." → "서비스 이용 준비가 완료됐어요." → 홈 |

설명 포인트: 내 성향과 희망 조건이 **키링 안에** 저장된다. 이후 매칭 판단은 키링끼리 한다. 폰이 없어도 된다.

### 7. 홈 화면

| 화면 | 동작 | 결과 |
|---|---|---|
| 홈 (아래 탭: 홈 · 제안 · 채팅 · 마이) | **새 매칭 ON** 인지 확인한다. **내 키링** 카드에 "연결됨"이 보인다 | "새 인연을 기다리는 중" |

### 8. 오프라인에서 스쳐 가기 (핵심)

1. A와 B가 **폰을 내려놓고 키링만 들고** 서로 가까이 간다(1~2m).
2. 약 1분 함께 있는다. 키링끼리 블루투스로 서로를 알아보고, 조건이 맞는지 판정해 **만남 기록**을 남긴다.
3. 서로 멀리 떨어진다(다른 공간으로 이동).

설명 포인트: 이 단계에서 서버나 폰은 관여하지 않는다. 개인정보는 오가지 않고 판정 결과만 키링에 남는다.

### 9. 만남 기록 보내기

| 화면 | 동작 | 결과 |
|---|---|---|
| 홈 > **내 키링** (또는 마이 > 키링 관리) | **최신 설정 확인·동기화** 를 누른다. A, B 둘 다 한다 | "키링의 만남 기록을 확인하고 있어요." → "서버 접수와 키링의 정리를 확인했어요." |

설명 포인트: 두 사람의 기록이 **둘 다** 서버에 도착해야 만남으로 인정된다. 한쪽 기록만으로는 제안이 만들어지지 않는다.

### 10. 제안 확인과 매칭 이유

| 화면 | 동작 | 결과 |
|---|---|---|
| 아래 탭 **제안** ("받은 제안 / 스쳐 간 인연을 다시 만나보세요") | 새로 온 제안 카드를 누른다. 푸시 알림으로도 들어올 수 있다 | 상대의 닉네임·나이·소개와 남은 응답 시간 |
| 제안 상세 | **매칭 이유** 를 본다 | AI가 두 사람의 성향테스트 결과로 만든 "왜 잘 맞는지" 설명 |

### 11. 수락

| 화면 | 동작 | 결과 |
|---|---|---|
| 제안 상세 | **수락하기** → "이 제안을 수락할까요?" 에서 **수락하기** | A만 수락한 상태: "상대 응답을 기다리는 중" |
| (B의 폰) 제안 상세 | B도 **수락하기** | 매칭 성사 → 채팅방이 만들어지고 두 사람에게 알림 |

설명 포인트: 둘 다 수락해야 대화가 열린다. 한쪽이 **거절하기** 를 누르면 "매칭이 성사되지 않았어요".

### 12. 채팅과 대화 주제 추천

| 화면 | 동작 | 결과 |
|---|---|---|
| 아래 탭 **채팅** ("인연을 대화로 이어가 보세요") | 새 채팅방("첫 인사를 건네 보세요")을 누른다 | 채팅방, 위쪽에 "대화를 시작해 볼까요?" 추천 질문 |
| 채팅방 | **대화 주제 추천** 의 질문 카드를 누른다 | 질문이 입력창에 들어간다 → 전송 |
| (B의 폰) 채팅방 | 답장을 보낸다 | 실시간으로 메시지가 오간다. 앱이 꺼져 있으면 푸시 알림 |

설명 포인트: 추천 질문은 두 사람이 설문에서 고른 공통 관심사로 AI가 만든다. 채팅방은 만든 날부터 7일간 쓸 수 있다.

### 13. 안전 기능 (신고·차단)

| 화면 | 동작 | 결과 |
|---|---|---|
| 채팅방 오른쪽 위 메뉴 | **신고하기** 를 누른다 | 신고 사유 선택 (욕설·모욕·협박 / 성희롱 / 스팸·광고 / 기타) |
| 신고 | 사유를 고르고 **증거 메시지 선택** 에서 메시지를 체크한 뒤 제출 | 신고 접수 |
| 채팅방 메뉴 | **차단하기** → "이 상대를 차단할까요?" 에서 **차단하기** | "상대를 차단했어요" — 제안과 채팅이 모두 끝나고 다시 매칭되지 않는다 |

> 차단은 되돌릴 수 없으니 시연 맨 마지막에 하거나 화면만 보여 주고 **돌아가기** 를 누른다.

### 14. 마이 (설정)

| 화면 | 동작 | 결과 |
|---|---|---|
| 아래 탭 **마이** | **매칭 설정** 을 눌러 희망 나이를 바꾸고 저장한다 | "키링에 적용을 기다리고 있어요" → 동기화하면 "키링에 최신 설정이 적용됐어요" |
| 마이 | **성향테스트**, **알림 설정**, **약관과 도움말**, **로그아웃**, **회원탈퇴** 를 훑어본다 | 각 화면 이동 |

설명 포인트: 조건을 바꾸면 키링에도 다시 보내야 적용된다.

## 시연 중 문제가 생기면

| 증상 | 대처 |
|---|---|
| 키링이 목록에 안 뜬다 | 폰 블루투스·위치를 확인하고 키링을 폰에 더 가까이 둔다 |
| 동기화 후에도 제안이 안 온다 | 두 사람 **모두** 동기화했는지 확인한다. 함께 있은 시간이 짧았으면 다시 1분 이상 함께 있다가 떨어진 뒤 동기화한다 |
| "아직 보내지 못한 기록이 있어요" | **만남 기록 다시 확인** 을 누른다. 계속되면 앱을 완전히 종료했다 다시 열고 동기화한다 |
| 같은 두 사람으로 다시 시연한다 | 이미 매칭된 사이는 새 제안이 생기지 않는다. 다른 계정·키링 조합을 쓴다 |
| 매칭 이유가 늦게 뜬다 | AI 응답을 기다리는 중이다. **설명 상태 확인** 을 누른다 |
