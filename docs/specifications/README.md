## 관리 원칙

- 새 기능·정책 변경은 MVP 요약과 상세 명세, 관련 검증 기준을 함께 대조한다.
- UX 초안이 최신 기능 기준과 다르면 기능 명세를 우선한다. UX 그림을 갱신하기 전에는 최신 기준 반영 완료로 표시하지 않는다.
- 날짜가 붙은 검토 기록은 근거를 보존하고, 당시 미정·보고와 현재 확정·실제 검증을 구분한다.
- 개인 파일의 절대 경로나 저장소 밖 상대 경로를 팀 문서에 연결하지 않는다. 출처는 자료 목록으로 식별한다.
- 계약·ERD 개인 자료를 다시 팀 저장소에 추가하지 않는다. 기존 원격 커밋·다른 브랜치의 과거 자료까지 삭제한 것은 아니다.
