**등록 완료 API·FE 판정(2026-10-22 확인):** `POST /api/v1/users/me/profile/complete`는 요청 본문 없이 호출하며 성공은 `200 { onboardingStatus }`, 필수값 누락은 `400 PROFILE_INCOMPLETE`다. FE는 서버가 반환하는 `completed`로 명시적 등록 완료 여부를 판단한다. 필수 입력을 모두 임시 저장한 것만으로 완료를 추정하지 않는다. 등록 전 성별·생년월일 수정은 허용하고 등록 후 다른 값으로 변경하면 `422 PROFILE_FIELD_LOCKED`다. 같은 값 재전송과 이미 등록한 프로필의 완료 재요청은 중복 등록으로 처리하지 않는다.

**배포 전 DB 확인:** 등록 시각은 `profiles.completed_at`에 기록한다. 순철은 배포 전에 가을과 대상 DB의 컬럼 추가 여부·적용 순서, 기존 회원 데이터가 있을 때의 등록 완료 이행 기준을 확인한다. 필수값이 채워졌다는 이유만으로 기존 회원의 완료 시각을 임의 채우지 않는다. 실제 컬럼 적용·기존 데이터 이행·배포 완료는 아직 확인하지 않았으며 FE는 DB 값을 직접 추정하지 않고 서버의 `completed`를 사용한다.

흡연·음주는 답을 미리 선택하지 않으며 ‘모름/비공개/상관없음’을 추가하지 않는다. 필수 응답이라는 이유로 생활 조건 불일치를 매칭 제외 사유로 쓰지 않는다. 종교 미입력을 무교로 추정하지 않는다. 생년월일 직접 입력은 실제 본인·연령 인증 완료가 아니다. 별도 인증·스토어 설정은 앱 개발 이후 출시 준비 단계에서 결정한다.

**흡연·음주 선택지 중복 안내(2026-10-23 사용자 확정):** 복수 선택지에 해당하는 경우 “나를 가장 잘 설명하는 항목 하나를 선택해 주세요”라고 안내하고 사용자가 직접 하나를 고른다. 술자리에서만 전자담배를 피우면 ‘전자담배’와 ‘술마실때만 가끔흡연’ 중, 중요한 자리에서 월 1회 마시면 ‘중요한 자리일때만’과 ‘월 1회이하’ 중 본인이 더 적절하다고 생각하는 항목을 선택한다. 기존 흡연 4개·음주 6개 선택지와 각 항목의 필수 단일 선택·기본 미선택을 유지한다. 종류/상황/빈도에 시스템 우선순위를 두거나 선택을 자동 변경하지 않는다. 저장 성공한 선택값을 그대로 공개하며 이 안내를 근거로 점수 환산·매칭 제외 조건·추가 입력을 만들지 않는다. 기존 v8 계산과 프로필의 목표 정책 차이 및 입력 연결 검토는 POL01에 유지한다.

**프로필 음주 횟수의 단위(2026-10-23 사용자 확정):** 프로필의 월/주 음주 횟수는 술을 마신 날의 수를 기준으로 안내한다. 같은 날 여러 번 또는 여러 술자리에서 마셔도 1회로 센다. 예를 들어 토요일 점심과 저녁에 각각 술을 마셨다면 2회가 아니라 1회이며, 서로 다른 이틀에 마셨다면 2회다. 안내 문구는 “음주 횟수는 술을 마신 날을 기준으로 선택해 주세요. 같은 날 여러 번 마셔도 1회로 세어요.”로 작성한다. 기존 음주 6개 선택지·필수 단일 선택·기본 미선택과 본인이 가장 잘 설명하는 하나를 선택하는 기준은 유지한다. 자기보고 선택을 돕는 설명이며 음주 날짜/술자리별 입력이나 자동 측정 기능을 추가하지 않는다. 기존 선택값/저장 코드를 자동 변경하거나 주간 응답을 월간 일수·v8 응답·매칭 점수로 자동 환산하지 않는다. v8 계산과 프로필 목표 정책의 차이는 POL01에 유지하며, 이번 결정은 실제 화면 안내 적용·앱 검증 완료를 뜻하지 않는다.

**음주 ‘중요한 자리일때만’의 설명(2026-10-23 사용자 확정):** 개인적으로 특별하다고 생각하는 모임도 포함한다. 안내 문구는 “평소에는 마시지 않고, 본인이 특별하다고 생각하는 자리에서만 마셔요”로 작성한다. 친구 결혼 축하 모임·가족 기념일 등이 예시이며 업무·의례상 꼭 필요한 자리로 한정하지 않는다. 예시 모임을 필수 조건이나 고정 목록으로 사용하지 않는다. 월/주 횟수 선택지와 겹치면 기존 기준대로 본인이 가장 잘 설명하는 항목 하나를 선택한다. ‘중요한 자리일때만’이라는 선택지와 저장 코드 SPECIAL_OCCASIONS_ONLY, 기존 음주 6개 선택지·필수 단일 선택·기본 미선택을 유지한다. 모임 종류/사유 입력·증빙·자동 분류를 추가하거나 기존 선택값·v8 응답·매칭 점수를 자동 변경하지 않는다. 실제 화면 안내 적용·앱 검증은 별도다.

**프로필 ‘흡연’ 선택지의 범위(2026-10-23 사용자 확정):** 마지막 ‘흡연’ 선택지는 담배 종류와 관계없이 흡연 전반을 포함한다. 안내 문구는 “일반 담배·전자담배 등 담배 종류와 관계없이 흡연하는 경우를 포함해요.”로 작성한다. 전자담배만 피우는 사람도 ‘흡연’을 선택할 수 있으며 일반 담배를 피우는 경우로 한정하지 않는다. ‘전자담배’ 또는 ‘술마실때만 가끔흡연’과 겹치면 기존 기준대로 본인이 가장 잘 설명하는 항목 하나를 선택한다. 전자담배 사용자를 반드시 ‘전자담배’로 분류하거나 병용자/술자리 흡연자의 선택을 자동 변경하지 않는다. 기존 흡연 4개 선택지·저장 코드·필수 단일 선택·기본 미선택과 저장값 그대로 공개하는 기준을 유지한다. 추가 종류/빈도 입력·점수 환산·매칭 제외 조건을 만들지 않으며, ‘흡연’ 선택값만으로 구체적인 담배 종류나 빈도를 추론하지 않는다. 이 설명은 프로필 선택지의 제품 의미이며 실제 화면 안내 적용·앱 검증은 별도다.
