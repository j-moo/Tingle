인프라는 순철이 현재 맡고 있음을 사용자에게 확인했다. 서버 배포·CI/CD 등 세부 준비 상태와 범위는 순철과 확인하며, 인프라 담당 확인을 구축/배포 완료로 표시하지 않는다. 재준이 테스터 모집·피드백 취합과 문의 응대 창구를 맡고 기술 문제를 §2.2의 해당 개발 담당에게 연결한다. 테스트 빌드 취합은 순철, 테스터 전달·운영 웹 화면 FE는 재준으로 확정했다. 운영 API/권한 검사는 가을, 채팅 보관/삭제 연동은 영빈이 맡는다. 상세 범위는 §2.3을 따른다. 서비스 운영 및 운영 계정·권한 관리는 재준, 개발·장애 대응은 나머지 다섯 명으로 확정했다. 조회/처리 역할은 §2.6을 따르며 잔여 판단 기준/구현은 POL04·POL07·DES11에서 확인한다. 담당 확정을 실제 권한 설정 완료로 보지 않는다. 운영 API 구현 담당을 서비스 운영 권한자로 자동 지정하지 않는다. 10월 23일까지 접근 권한·작업량·구현 계획을 REVIEW01에서 확인한다. 두 BE와 FE·인프라를 병행하는 순철의 작업량을 함께 확인하고, 실제 공수 점검 후 변경이 필요하면 PM·팀과 조정하고 문서에 남긴다.

## 6. 남은 정책 결정과 구현 설계

2026-10-21 기준 정책 본문·기능별 검토란·기존 미정 목록을 함께 대조한 통합 목록이다. 변경 이력에만 남아 있는 과거의 미정 사항은 현재 미정으로 세지 않는다. 분류 자체는 팀 승인이나 구현 완료를 뜻하지 않는다. 이후 사용자와 확정한 정책·업무 배정은 각 행과 §2.1~2.2에 표시한다. 정책 원본은 기준 정책, 기능 동작은 §3을 유지하고 남은 작업 목록은 이 절에서 관리한다.

- **정책(POL):** 사용자가 할 수 있는 일, 입력의 의미, 정보 이용/보관 범위가 달라지는 결정. 재준이 관련 담당자의 근거·가능 범위를 확인하고 결정한다.
- **구현(DES):** 확정된 동작을 구현하기 위한 화면·API·ERD·알고리즘·통신·복구 설계. 담당자가 안을 작성하며 모든 필드나 기술 선택을 PM이 결정할 필요는 없다. 구현 제약으로 확정 동작을 바꿔야 하면 정책 검토로 되돌린다.
- **후속(LATER):** 이미 프로젝트 이후나 출시 준비로 분리한 범위. 이번 분류를 이유로 기존 MVP 기능을 추가로 제외하지 않는다.
- **검토 완료 조건(REVIEW):** 요구사항 대조·담당 확정·팀 승인 등 문서를 마무리할 작업. 기술 설계나 실제 테스트 완료와 구분한다.

아래 협의 대상은 검토 경로이며 확정 구현 담당은 §2.2를 따른다. 전체 목표 일정은 §2.1, 업무 분담은 §2.2에 확정했으며 실제 공수·세부 일정·달성 가능성, 순철의 인프라/배포 준비·재준의 운영 창구 준비 및 확정된 앱 빌드/운영 화면의 구현 계획은 REVIEW01에서 확인한다.

**계산 정책 변경 확정(2026-10-25 후속 사용자 결정):** 성현의 후속 제안을 사용자가 “성현님 제안으로 변경 — 선호 점수와 명시적 제외를 구분”으로 승인했다. 같은 날 앞서 결정한 생활정보 점수/자동 제외 미반영 방침을 대체한다. `SIS-Q-1.1-100` 참조 엔진 기반 제품 계산 규칙을 사용하며, 흡연·음주·종교는 상대에 대한 허용 범위와 실제 상대 정보의 부합도를 일반 매칭 점수에 반영한다. 단순히 두 사람의 생활정보가 다르다는 이유만으로 강제 제외하지 않는다. 다만 선호 불일치로 점수가 낮아져 최종 기준 미달로 매칭되지 않을 수 있다. 프로필 공개·수락/거절 판단은 유지하며 ‘생활정보가 매칭에 영향 없음’으로 안내하지 않는다.

Q97의 명시적 제외는 **흡연·자녀 계획·종교·문신 중 최대 2개**다. 각 방향에서 사용자가 선택한 항목의 허용 범위를 상대가 벗어나면 총점과 무관하게 제외한다. 선택하지 않은 항목의 불일치만으로 강제 제외하지 않으며, 일반 점수 판정은 별개다. 음주는 Q97 제외 항목으로 추가하지 않고 일반 선호 점수에만 반영한다. UNKNOWN/ANY를 강제 선택이나 불일치로 바꾸지 않으며, 미확인 값의 판정 보류·coverage 처리는 계산 계약과 검산 사례로 구분한다. 이번 결정은 자녀 계획·문신의 일반 점수 세부 산식을 새로 정한 것이 아니다.

만 19세 이상·양방향 희망 나이는 Q97과 무관한 필수 조건으로 항상 검사한다. 성별·사진 옵션·차단/재매칭 제한 등 기존 조건도 유지한다. 확인한 develop f5224c9의 Q097 catalogue와 참조 엔진에는 `age` 선택지/분기가 남아 있어 성현 회신의 ‘나이 선택지 없음’과 다르다. 최종 제품 문항은 위 네 항목으로 맞추되, 담당자의 기준 브랜치·커밋/문항 버전을 확인하고 나이 중복 제거·기존 응답 이행을 별도 버전으로 정리한다. 원본 catalogue/완료 응답을 조용히 덮어쓰지 않는다. metadata 19~100과 제품 나이 상한 없음, 프로필/설문 실제값의 우선 출처·변환·변경 시 새 기기 사본 반영은 S01~03 계약 잔여다.
