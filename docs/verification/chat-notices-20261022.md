## 웹 명세 반영 중간 검증

- 노션 안내 ACK: 본인 방·안내 권한, 종료 후 기존 ACK, 멱등 키와 본문 없음, 첫 안내 확인 전 메시지 제한, 이른 종료 안내 ACK 거부, 안내 UUID 매핑 및 공급자 접수와 화면 확인 구분을 현재 계약에 반영했다. 과거 원문 보존 구역은 유지했다.
- 노션 설치 등록: 성공 응답 문단에 필수 `serverTime`, `bindingId`와 연결 번호 유지·재발급 조건을 반영했다. 응답 표의 `bindingId` 행, 인증·오류·토큰 설명 정리는 남았다.
- 노션 ERD: `push_installations.session_family_id`를 `login_family_id`로 수정하고 재조회했다. 해당 표는 기존 `binding_id`, `linked_at`을 포함해 9컬럼이다. 다른 채팅 표의 재검증은 남았다.
