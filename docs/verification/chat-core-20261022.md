## 적용 경계

- 검증은 로컬 HTTP/JPA/PostgreSQL이다. 실제 앱·실시간 전달/푸시·공용 DB·외부 AI 제공자·배포·원격 CI 검증은 아니다. Docker 기존 데이터는 변경하지 않았으며 테스트 전용 컨테이너만 사용했다.
- 노션·ERDCloud 웹 저장은 이번 범위에서 하지 않았다. 저장소 계약/ERD 검증 완료와 웹 반영 완료를 구분한다.
- 첫 입장/종료 안내·알림, 신고 보관/삭제·운영 조회, 철회 이벤트의 종료 저장·AI 작업 취소는 후속 작업이다. 읽음 기록은 메시지 보관/삭제 단위에 함께 포함해야 한다.
- 기존 회원 동의 전환 화면/유예·최종 안내문구와 실제 적용 시점은 작성자 확인 대상으로 유지한다. 공용 서비스에서 임의 전환하지 않았다.
- FE는 읽음 UUID ACK·readByPartner·메시지 원문 길이/바이트 검사·치환 결과 전체 표시·성사 제안의 채팅 목록 이동을 대응해야 한다. 기존 DB 행의 공개 UUID/source/key 이관과 앱 적용 준비는 실제 배포 전에 확인한다.
