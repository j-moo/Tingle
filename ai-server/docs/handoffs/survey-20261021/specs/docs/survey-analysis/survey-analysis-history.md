## 1 버전 이름을 읽는 법

- `SIS 0.1`, `SIS-0.2`, `SIS-Q-0.3`, `MATCH-*`, `PARTNER-*`, `READING-*`는 당시 기록에 쓰인 이름이다. 과거 문서에 표기가 혼재하므로 하나의 연속 버전이라고 임의 변환하지 않는다.
- `v8`, `v10`, `v14`, `v15`는 목업 게시·산출물 구분이다. 설문 스키마나 팀 기획안 v1.2, 문서 v0.3과 같은 버전이 아니다.
- 현재 설문 `SIS-Q-1.1-100`, 표현 `SIS-WORDING-20261020-1`, 유형 `SIS-TYPE-INITIAL-1.0`, 나이 `SIS-AGE-1`, 참고 유형 `SIS-TYPE-REF-1`, 공개 게시 `v15`를 별도로 기록한다.
- 아래 H01~H18은 이력 정리를 위한 번호다. 실제 배포 버전이 아니다. 과거 각 변경의 정확한 게시 시각·커밋이 보존되지 않은 경우 추정하지 않았다.

2026-10-20 조회 당시 Jira41·42에는 이전v8 참조가 남아 있었고,34·36에는 생년월일 기반·상한 없는 양방향 필수 나이 조건과 별도의 흡연·음주·종교 프로필이 기록돼 있다. 이는 과거 조회 기록이며 이번 표기 정리에서 Jira를 재조회하지 않았다. 로컬 현재 기준과 미해결 정책의 선택지는 [문항 정의서](personality-survey-v1.md)의 결정 항목을 따른다. 현재 목업과 같은 정책이 아니다. 문서화만으로 충돌을 해소하거나 목업을 운영 정책으로 승격하지 않는다.

41번은 문항·흐름·입력 버전,42번은 개인 점수·유형·해석,36번은 두 사람 비교 계약을 담당한다. 검토·승인·develop 병합 여부를 별도로 남긴다. 검증된 기존 척도를 참고했다는 사실과 자체100문항의 신뢰도·타당도가 검증됐다는 주장을 구분한다.

## 7 이번 문서 반영 범위

설문 문서가 없던 현재38번 브랜치를 전환하지 않고, 이전 문서 커밋843dd1d의 docs/survey-analysis 자료만 가져와 최신 문항 정의·계산 정의·변경 이력·폴더 안내를 갱신했다. 초기 초안과 v14까지의 README 보존본은 과거 기록이므로 원문을 바꾸지 않았다. 만남·제안 API 문서와 백엔드 작업은 수정 대상이 아니다. 이번 요청에는 프로젝트 커밋·푸시가 포함되지 않는다.
