# 설문 인계 미결정 정책과 추천안

2026-10-21 / 관련 Story S15P31E106-41 / 상태: 검토용. 아래 추천은 사용자나 팀의 승인된 정책이 아니다. 현재 문항·계산 코드는 그대로다.

결정 항목 원문은 [문항 정의서](specs/docs/survey-analysis/personality-survey-v1.md#정책-차이의-결정-항목--2026-10-21)를 단일 기준으로 사용한다. D01~D10의 선택지·영향·기존 응답 처리도 해당 절에서 확인한다.

| ID | 결정할 내용 | 추천 방향 | 이유 |
| --- | --- | --- | --- |
| D01 | 나이 입력 기준 | 서비스는 프로필 생년월일 기준. 목업은 체험용 나이 입력으로 구분하되 범위 판정은 서비스와 맞추기 | 중복 입력과 생일 이후 오래된 나이 방지. 이미 정한 만19세 이상·상한 없음 정책을 다시 미정으로 돌리지 않음 |

검토 순서: D03·D04에서 계산에 사용할 정보를 정하고, D01·D02 및 D05~D07에서 입력·저장 의미를 맞춘 뒤 D08~D10에서 계산·표시·이관을 정한다. 일정이나 새 담당 배정을 의미하지 않는다.

## 구현 전에 함께 확인할 계약 불일치

- [버전 파일 계약](specs/docs/contracts/survey/versioning.md)은 answers_json, [SQL](specs/docs/database/schema.sql)은 response_json으로 표기한다. 구현 전 저장 필드·구조를 맞춘다. 이번 인계에서 임의 수정하지 않았다.
- 문항 catalogue만으로 채점·정책·분석·매칭을 실행할 불변 파일 묶음이 완성된 것은 아니다. 파일 형식·배포 위치·releaseId 대응을 합의해야 한다.
- 로그인45번 브랜치는 SURVEY_REQUIRED를 선언했지만 OnboardingService에서 설문 검사를 아직 생략한다. 설문 완료·정보 부족을 가입 준비 상태와 연결할 필요가 있다.

## 결정 기록

각 D항목에 선택안·이유·적용 대상·변경 문항·계산 영향·기존 응답 처리·검토자·승인 근거를 남긴다. 기본 검토는 Jira41에 기재된 이재준(PM·FE), 영향 파트는 FE·BE·AI이며 키링 형식 변경 시 IOT 검토도 필요하다. 작성자 본인 승인은 인정하지 않는다.
